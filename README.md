# Mya Thet Chel — Portfolio 5.0

A static, GitHub Pages ready portfolio. Open `index.html` to preview it locally.

The page uses `styles.css`, `v5.css`, `script.js`, and the `assets/` directory. To replace the current GitHub Pages version, put the **contents of this folder** in the root of the portfolio repository.

Version 5.0 keeps the character and paper-airplane hero, then presents Datastore and Robot Platform as the primary product cases, followed by design-system and web work, career experience, working approach, skills, and contact information.
